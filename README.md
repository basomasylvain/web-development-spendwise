# Week 1 Assignment: Build the Static Skeleton of Your Budget Tracker

## Overview
This repository contains the Week 1 foundation for the **Personal Budget & Expense Tracker (SpendWise)** project in **Web Development Fundamentals** at **PLP Academy**. It establishes a clean, semantic HTML structure linked to an external CSS stylesheet using element, class, and ID selectors.

## Project Files
- `index.html` — Semantic HTML5 skeleton featuring the page header, the **Add Expense** input section (expense name, amount, and category), and the **Your Expenses** placeholder section.
- `style.css` — External stylesheet demonstrating element selectors (`body`, `h1`, `input`, `select`), ID selectors (`#app-header`, `#add-expense-section`, `#expenses-list-section`), and class selectors (`.card`, `.form-group`, `.subtitle`, `.placeholder-text`).
- `README.md` — Project overview, structure, and instructions for viewing and inspecting with Browser DevTools.

## How to Run & Inspect
1. Open `index.html` in any web browser (Chrome, Firefox, Edge, etc.).
2. Right-click anywhere on the page and select **Inspect** to open Browser Developer Tools.
3. Select elements in the **Elements** panel and test live CSS edits in the **Styles** pane.
